# WhiteDNS GitHub Pages site

Static GitHub Pages index for `github.com/WhiteDNS`.

## Deploy

Copy these files into the repository that backs the GitHub Pages domain:

- `index.html`
- `styles.css`
- `tokens.css`
- `app.js`

Then enable GitHub Pages from the repository settings. The page includes a fallback repository snapshot and refreshes from the public GitHub API in the browser.
